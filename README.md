# Kiosco El Rápido

App frontend de un kiosco de barrio: catálogo, filtros, detalle de producto, carrito y simulación de pedido.

## Stack

Vite + React + TypeScript + react-router-dom, con CSS simple.

## Scripts

- `npm run dev` — servidor de desarrollo
- `npm run build` — chequeo de TypeScript y build de producción
- `npm run preview` — previsualización del build
